# CV contact icons

- `mail.svg`: Font Awesome Free, regular envelope.
- `website.svg`: Font Awesome Free, globe.
- `google-scholar.svg`: Font Awesome Brands, Google Scholar.

The vector paths are exported from the installed `react-icons/fa6` package,
which is already used by the website. All three icons use the same ink color;
their paths are unchanged. Font Awesome icons are copyright Fonticons, Inc.,
and licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See the [Font Awesome Free license](https://fontawesome.com/license/free).

The original SVGs are kept here so Typst can embed them as vectors in the PDF.
